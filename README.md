# 『15秒のおまじない』毎日自動投稿システム

一日のさまざまな場面で「小さな勇気が要るとき」に、心の中で唱える短い言葉を渡す
縦型ショート動画シリーズの自動投稿システム。カード2枚＋AI音声で約7〜15秒。

- 台本生成・PDCA: Gemini API（無料枠）。失敗時は採用済みストック32組から
  分類ラウンドロビンで出す
- 音声: Edge-TTS（予備 gTTS）／カード: Pillow／合成: FFmpeg
- 投稿: YouTube Data API（専用チャンネル『15秒のおまじない』）
- 記録: Google スプレッドシート『おまじない ログ』（分類列つき）
- 実行: GitHub Actions、毎日 06:12 JST（正時の混雑を避けて12分ずらし。2026-11-23決定）

セットアップ手順は SETUP_GUIDE.md を参照。
運用マニュアルは Gemini 策定（2026-11-22）。
